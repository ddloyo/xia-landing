# XIA · Insights × Analytics — Landing page

Landing page pública de XIA, independiente del [portafolio de proyectos de demostración](https://github.com/ddloyo/portfolio) (repo separado, para poder seguir compartiéndolo por su cuenta).

Sitio estático de una sola página (`index.html`, sin build step) publicado con GitHub Pages. Copy migrado de `XIA-Propuesta-de-Valor-v3.pdf`, con el sistema visual de marca de XIA (teal / dorado / crema, Barlow Condensed + Source Sans 3).

## Estructura

- Hero — posicionamiento: "un dueño fraccional para tus datos"
- Problema — los 6 síntomas validados en campo (ago 2026)
- Evidencia — 3 estadísticas citadas (Gartner, Domo, campo XIA)
- Servicios — Data Storytelling Express y Micro Data Office
- Portafolio — enlaza al repo de portafolio (13 proyectos demo)
- Contacto — CTA de diagnóstico gratuito de 30 min (WhatsApp / correo)

## Publicar en GitHub Pages

Settings → Pages → Source: rama `main`, carpeta `/ (root)`.
